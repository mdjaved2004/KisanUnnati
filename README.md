# 🌾 Kisan Unnati (Year: 2025)

## 📌 About Kisan Unnati

Kisan Unnati is a comprehensive web platform designed to empower modern farming by bridging the gap between traditional practices and digital solutions. It provides farmers with real-time information, direct market access, and tools for better decision-making, ultimately driving productivity, profitability, and digital inclusion in Indian agriculture.

---

## 🚜 Key Features

- 🌾 **Digital Marketplace** – Connects farmers directly with buyers, reducing intermediaries.
- ☁️ **Weather Forecasting** – Location-based weather information and alerts to help farmers plan farming activities.
- 🦠 **Crop Disease Diagnosis** – Image-based crop disease detection.
- 📊 **Market Analysis** – Provides market price information to support better selling decisions.
- 🏛 **Government Schemes Portal** – Simplified access to farmer-focused government schemes.
- 🗣 **Voice-First Interaction** – Improves accessibility for farmers with limited technical literacy.
- 📱 **Responsive UI** – Mobile-friendly and bilingual (Hindi + English) user interface.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/KisanUnnati.git
```

### 2. Run the Backend

Navigate to the backend directory:

```bash
cd KisanUnnatiBackend
```

Configure your MySQL database credentials in `application.properties`.

Run the Spring Boot application:

```bash
mvn spring-boot:run
```

### 3. Run the Frontend

Open another terminal and navigate to the frontend directory:

```bash
cd KisanUnnatiFrontend
```

Install dependencies:

```bash
npm install
```

Start the React application:

```bash
npm run dev
```
